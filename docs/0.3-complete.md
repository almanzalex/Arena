# Arena 0.3 complete — handoff to 0.4

**Status:** Done (2026-07-21)
**Package:** `0.3.0`

## Locked claim

1. The same portable policies/evaluation run on native PettingZoo and the frozen OpenEnv
   RPS runtime with verified trace semantics and recorded transport failures.
2. OpenSpiel `tic_tac_toe` runs match/eval through the same entrypoints with masks,
   provenance, and a frozen reference trace. No broader catalog is claimed.
3. Gimitest attaches as an evaluation provider; policy/task/config lineage is complete.
4. `file://` and Hugging Face store adapters mirror artifact bytes without changing
   `sha256:…` identity; verified pull refuses mutation.
5. Native 0.2 flows remain offline and do not import external integrations.

## Prove it locally

```bash
pip install -e '.[dev]'
pip install --no-deps gimitest==1.0
pytest -q
bash examples/eval/run_demo.sh
pytest -m slow tests/acceptance/test_eval_hermetic.py::test_eval_hermetic_venv \
  tests/acceptance/test_u01_hermetic.py::test_u01_hermetic_venv -q
```

Integration-specific evidence lives in `tests/acceptance/test_openenv_equivalence.py`,
`test_openspiel_e2e.py`, `test_gimitest_provider.py`, and the file/HF mirror tests.
The consolidated release record is [0.3-evidence.md](0.3-evidence.md).

# Arena 0.4 — former product boundaries made executable

**Status:** Implemented on `codex/0.4-boundaries`; release tag not created.

Recorded results: [0.4-evidence.md](0.4-evidence.md).

0.4 deliberately leaves the 0.3 tag and claims unchanged. It adds four qualified
capability slices and an executable simulation that composes them.

| Gate | Claim | Evidence |
|---|---|---|
| L-01…L-04 | Explicit dynamic AEC birth/removal lifecycle | `tests/acceptance/test_dynamic_aec_lifecycle.py` |
| TR-01…TR-04 | Portable dataset → seeded behavior cloning → verified reusable policy | `tests/acceptance/test_training_recipe_e2e.py` |
| OS-05 | Frozen Connect Four trace and ordinary match/eval path | `examples/tasks/openspiel-connect-four-trace.yaml` |
| ST-07 | HF/OCI/W&B/MLflow simulated verified round trips | `tests/unit/test_boundary_stores.py` |
| U-04 | All former boundaries compose in one user journey | `tests/acceptance/test_boundary_demo.py` |

Run the combined journey:

```bash
bash examples/boundaries/run_demo.sh
```

It executes forced agent birth/removal, trains from materialized match trajectories,
reuses the resulting policy in a fresh match, verifies the frozen Connect Four trace,
and pushes/pulls that policy through four explicit provider simulations without
changing identity.

Qualify the dynamic task itself through the public adapter seam:

```bash
arena adapter qualify examples/tasks/dynamic-lineup.yaml \
  --trace-suite examples/tasks/dynamic-lineup-trace.yaml \
  --out dynamic-qualification.json
```

## Live backends

Simulation is not live-backend evidence. After authenticating with the provider's
normal tooling, run:

```bash
python examples/boundaries/live_store_smoke.py \
  training-run/policy.arena hf://models/ORG/REPO/arena \
  --out /tmp/restored-live.arena
```

The same command accepts `oci://`, `wandb://`, and `mlflow://`. It refuses
`?simulate=` so its result cannot be confused with the local test.

## Remaining honest limits

- Dynamic support is qualified for AEC and requires every potential agent plus
  explicit policy-digest eligibility for births. Arena never guesses a policy.
- Training freezes one algorithm: behavior cloning over Discrete actions and
  Discrete/Box observations. Additional algorithms need separate recipe cases.
- OpenSpiel remains a frozen deterministic sequential catalog. Chance and
  simultaneous nodes are rejected.
- Provider services, auth, billing, retention, and dashboards remain upstream.

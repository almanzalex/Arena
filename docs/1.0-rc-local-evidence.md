# Arena 1.0.0rc1 local evidence

Date: 2026-07-25

Branch: `codex/1.0`

Verdict: local implementation proof passes; final `v1.0.0` release proof is
not yet complete.

This record supersedes the pre-rename local proof. Arena schema identifiers,
artifact suffixes, plugin entry points, and environment variables participate
in executable contracts, so all content identities below were regenerated and
reverified rather than relabeled.

This record is deliberately not an `arena.release-evidence/v1` index. A real
release index must be produced outside the source commit, content-bind the exact
wheel/sdist and R-01…R-14 records, use a release-manager key delivered through
an independent trust channel, and pass `arena release verify`.
